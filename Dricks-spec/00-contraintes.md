# Drikx — Contraintes de design — langue pour penser (profil pseudoLuc)

Objectif : une langue dont la grammaire rend les paresses cognitives coûteuses à dire.
Pas un catéchisme lexical — une discipline syntaxique.

## Contraintes fermes

1. **Évidentialité obligatoire.** Toute proposition finie porte un morphème de source :
   - DIRECT — perçu ou vérifié par le locuteur (rang le plus haut : le mental ne remplace pas l'expérimental)
   - INFÉRENTIEL — déduit de traces ou de raisonnement
   - RAPPORTÉ — tenu d'autrui, source citable
   - CRU — croyance sans source ; existe, mais forme morphologiquement lourde, connotée comme faute épistémique
   L'assertion nue est agrammaticale. Questions et impératifs exemptés (pas d'assertion). Le futur prend l'inférentiel.

2. **Pas de voix passive, pas d'impersonnel.** L'agent est syntaxiquement obligatoire dans les procès agentifs.
   Agent inconnu → agent épistémique explicite (« quelqu'un-que-j'ignore »), marqué inférentiel.
   Les procès spontanés (pleuvoir, tomber) restent possibles.

3. **Aspect répétitif vs séquentiel**, grammaticalisé, non interchangeable :
   - RÉPÉTITIF — routine, cycle, maintenance
   - SÉQUENTIEL — étapes ordonnées vers un état nouveau

4. **Verbe initial** (VSO). L'action avant l'agent. Conséquences d'implication à tenir : prépositions, nom avant génitif.

5. **Phonologie percussive.** 3-4 voyelles ; dominante d'occlusives avec UNE série marquée ;
   clusters d'occlusives en attaque (/kt/, /pt/) ; syllabe cœur CVC ; mots courants 1-3 syllabes.
   Parfums grec ancien / sanskrit, sans copier leurs paradigmes.

6. **Ni politesse ni consensus.** Pas d'honorifiques, pas de vouvoiement.
   « Tout le monde le dit » = évidentiel RAPPORTÉ, sans forme valorisante.

7. **Lexique dense.** Peu de racines, chacune une grappe sémantique ; le sens fin par dérivation productive
   (agentif, résultatif, instrumental, abstrait, privatif au minimum). ≥ 2/3 d'items dérivés dans l'expansion.

## Garde-fous de génération

- QA de traduction : vérifier l'évidentiel phrase par phrase (issue prioritaire n°1).
- Refuser le passif de contrebande (moyennes/anticausatives sur procès agentifs).
- Le surprenant doit être structurel, pas décoratif.

## Nom de la langue

**Le Drikx** (décision du concepteur, prime sur tout — Principe B).
Anomalie assumée et documentée : /drikx/ est imprononçable en Drikx même
(/d/ absent de l'inventaire, coda /kx/ illicite). « Drikx » est donc un exonyme :
le nom que la langue porte au-dehors. À l'intérieur d'elle-même, elle se désigne
par le générique pratil, ou par adaptation phonologique régulière /tirks/
(t pour d, métathèse de coda vers C+s licite) si un endonyme est requis.
