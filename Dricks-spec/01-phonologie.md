# Drikx — Phonologie

Contraintes actives (rappel) : percussive, 3-4 voyelles, dominante d'occlusives, UNE série marquée,
clusters d'occlusives en attaque, CVC cœur, mots courants 1-3 syllabes, prononçable le ventre vide.

## Consonnes (IPA, phonémique)

|            | Labiale | Alvéolaire | Vélaire | Glottale |
|------------|---------|------------|---------|----------|
| Occlusive  | p       | t          | k       |          |
| Éjective   | pʼ      | tʼ         | kʼ      |          |
| Nasale     | m       | n          |         |          |
| Fricative  |         | s          | x       | h        |
| Vibrante   |         | r          |         |          |
| Latérale   |         | l          |         |          |

12 consonnes. Pas de série voisée (/b d g/ absents), pas de labiodentales, pas de glides :
l'inventaire est sec, sans sonorité de confort.

**Trait structurel n°1 — les éjectives sont grammaticales.** /pʼ tʼ kʼ/ n'apparaissent
(sauf rares exceptions expressives) dans aucune racine lexicale : elles sont réservées à la
morphologie épistémiquement dégradée — en premier lieu l'évidentiel CRU et les dérivations
péjoratives/privatives. La faute épistémique se crache, littéralement. Une racine à éjective
sonne immédiatement comme un mot suspect.

## Voyelles

| | Antérieure | Centrale | Postérieure |
|---|---|---|---|
| Fermée | i | | u |
| Ouverte | | a | |

Trois voyelles /a i u/, jamais longues, jamais nasales. Pas de diphtongues : deux voyelles
ne se touchent jamais (la morphologie insère /r/ épenthétique en cas de hiatus).

## Phonotactique

Syllabe : (C)(C)V(C). Attaques complexes permises : occlusive + occlusive (/kt/, /pt/, /tk/),
occlusive + liquide (/kr/, /tr/, /pr/, /kl/, /pl/), /s/ + occlusive (/st/, /sk/, /sp/).
Coda simple : une consonne parmi /p t k s x r l n m/ — jamais d'éjective, jamais /h/.
Codas complexes (deux consonnes), en **finale de mot uniquement**, trois familles :
  (a) sonante /r l n m/ + obstruante /p t k s x/  (/rk/ dans *nark*, /lt/ dans *malt*, /nk/, /rs/…) ;
  (b) sonante /r l/ + nasale /n m/  (/rn/ dans *karn*, /rm/…) ;
  (c) obstruante /p t k s/ + /t s/  (/kt/ dans *takt*, /st/ dans *kust*…), parfum grec.
En position médiane, la coda est toujours simple : les amas intervocaliques se résolvent
par attaque maximale (coda simple + attaque licite ; *taktut* → *tak.tut*).
/h/ n'apparaît qu'en attaque initiale de mot.

**Épenthèse /a/ aux frontières morphologiques (amendement 2026-07-30, cf. surprises
S5).** Symétrique du /r/ épenthétique des hiatus : quand une suffixation
consonne-initiale sur un radical à coda complexe produirait un amas illicite
(*taktsi*), une voyelle /a/ est insérée pour le résoudre (takt + -si → takt-**a**si).
Elle vaut en premier lieu pour les aspects -si/-tu → -asi/-atu (cf. grammaire §1.1).

**Trait structurel n°2 — la frontière lexical/grammatical est audible.** Tout mot lexical
(nom, verbe, adjectif) se termine par une consonne. Tout mot ou affixe purement grammatical
se termine par une voyelle. On entend la charpente et le liant sans dictionnaire.

## Suprasegmentaux

Pas de ton. Accent d'intensité fixe sur la syllabe initiale du mot lexical — le temps fort
frappe d'abord, comme le verbe vient d'abord.

**Trait structurel n°3 — l'accent dénonce.** Une seule exception à l'accent initial :
quand un verbe porte l'évidentiel CRU, l'accent se déplace sur le morphème évidentiel
lui-même. La croyance sans source est prosodiquement exhibée ; impossible de la murmurer
en fin de mot.

## Word Shapes (formes de mots)

- Items lexicaux : la plupart monosyllabiques CVC/CCVC ou disyllabiques ; les trisyllabes
  sont rares et presque toujours des dérivés. Finale consonantique obligatoire.
- Items grammaticaux : presque tous CV ou V, monosyllabiques ; finale vocalique obligatoire ;
  les seuls porteurs réguliers d'éjectives.
- Les attaques en cluster (/kt-/, /st-/, /pr-/…) sont fréquentes dans les racines,
  absentes des mots grammaticaux.

Matière sonore (sans sens, pour l'oreille) :
lexical : /takt/, /kram/, /stir/, /ktal/, /purk/, /prat/, /skim/, /turs/, /klap/, /xurt/, /nark/, /silp/
grammatical : /ka/, /si/, /u/, /ta/, /ru/, /pʼa/, /kʼu/

## QA (résumé)

Score 9/10. Issues traitées : (1) hiatus non défini → règle du /r/ épenthétique ajoutée ;
(2) statut de /h/ ambigu en coda → restreint à l'attaque initiale ; (3) codas complexes
contredisaient « coda = 1 C » → règle de coda finale élargie aux trois familles attestées
(sonante+obstruante, sonante+nasale, obstruante+t/s), calibrée sur le lexique (amendement
2026-07-30, session Claude Code T1 ; cf. surprises.md S1).
Ambiguïté résiduelle assumée : réalisations allophoniques hors périmètre du sketch.
